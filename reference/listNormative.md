# List registered normative references

List registered normative references

## Usage

``` r
listNormative(root = NULL)
```

## Arguments

- root:

  Registry root (see
  [`registerNormative()`](https://x-biosignal.github.io/PhysioClinical/reference/registerNormative.md)).

## Value

A `data.frame` of `id`, `version`, `modality`, `metric`, `access_level`
and `n`, newest version last.
