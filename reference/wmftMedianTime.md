# Median WMFT performance time

Summarises the Wolf Motor Function Test timed-task performance as the
median time across tasks, the conventional WMFT time summary.

## Usage

``` r
wmftMedianTime(times)
```

## Arguments

- times:

  Numeric vector of per-task performance times (seconds).

## Value

The median time (seconds).
