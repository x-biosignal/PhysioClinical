# Retrieve a registered clinical instrument

Retrieve a registered clinical instrument

## Usage

``` r
getInstrument(id)
```

## Arguments

- id:

  Instrument identifier.

## Value

The
[ClinicalInstrument](https://x-biosignal.github.io/PhysioClinical/reference/ClinicalInstrument.md).
