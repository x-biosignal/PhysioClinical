# PhysioClinical

<!-- badges: start -->
[![r-universe](https://x-biosignal.r-universe.dev/badges/PhysioClinical)](https://x-biosignal.r-universe.dev/PhysioClinical)
<!-- badges: end -->

Clinical outcome measures and responder analysis for the
[x-biosignal](https://github.com/x-biosignal) rehabilitation ecosystem:
validated outcome-measure scoring, MDC/MCID responder classification, ICF
tagging, and normative deviation scoring.

## Installation

```r
install.packages("PhysioClinical",
  repos = c("https://x-biosignal.r-universe.dev", "https://cloud.r-project.org"))
```
